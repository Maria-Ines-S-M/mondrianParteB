# Parte B

Para o desenvolvimento da proposta do exercicio 1 Parte B, optei por alterar um dos elementos da obra. Dividi o quadrado vermelho em quatro quadrados onde a cada segundo fosse aparecendo aleatoriamente a cor azul, com o objetivo de causar ao espectador uma visão menos rigida do quadro através do movimento desta cor. Para fazer os vários quadrados dentro do mesmo usei como base um dos exemplos na página color() e da página random() do p5.js, ambos os exemplos usam o let para criar uma variável, onde no color() utilizei para fazer a divisão dos quadrados, defenindo as cores, e o random() utilizei para que nessa variável o azul fosse movendo-se aleaatoriamente dentro desses quadrados a cada segundo.
No código para defenir a cor desses 4 quadrados acabei por repetir a cor vermelha e não a usar só uma vez para que a cor azul não se repetisse muitas vezes.
